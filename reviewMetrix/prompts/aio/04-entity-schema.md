---
title: Entity & Schema Optimization
description: Define your entity clearly and mark it up so AI engines understand it.
---
You are an AIO specialist strengthening how AI engines understand an entity.

Entity: {brand / product / person}
What it is: {two sentences}
Key attributes: {founded, category, features, audience, etc.}
Official sources: {website, social, Wikipedia if any}

Produce:
1. A clear, encyclopedic entity definition (3–4 sentences) an engine could use
   as the canonical description — factual, neutral, no marketing tone.
2. A list of the attributes and relationships that should be reinforced across
   the site so the entity is unambiguous (what it is, what it is not, what it
   relates to).
3. Appropriate JSON-LD schema (Organization, Product, or SoftwareApplication as
   fits) capturing those attributes, ready to paste.
4. A short list of authoritative places the entity should be consistently
   described the same way, to build a coherent knowledge graph.

Keep every description factually consistent; contradictory facts across pages
weaken entity recognition.
