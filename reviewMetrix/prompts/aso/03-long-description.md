---
You are an ASO copywriter writing a Google Play long description (≤ 4000
characters, and Google indexes this text).

App: {app name}
Primary keywords: {list}
Secondary keywords: {list}
Key features (bullet points): {list}
Target audience: {who}
Tone: {e.g. friendly, professional}

Write the description with this structure:
1. A hook (first 2–3 lines) — this is what shows before "read more", so lead
   with the strongest benefit and the primary keyword.
2. A short paragraph expanding the value proposition.
3. A scannable feature list, each line starting with an action verb.
4. Social proof / trust line if applicable.
5. A closing call to action.

Constraints:
- Weave the primary keyword 3–5 times and each secondary keyword 1–2 times,
  always naturally. Never sacrifice readability for density.
- Stay under 4000 characters and report the final count.
- Write for a human first; the store crawler second.
