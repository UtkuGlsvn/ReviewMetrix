---
title: Keyword Cluster & Intent Map
description: Group seed keywords into topic clusters mapped to search intent.
---
You are an SEO strategist.

Website / product: {name}
What it offers: {two sentences}
Seed keywords: {list}
Target audience: {who}

Do the following:
1. Group the seed keywords (and closely related terms you infer) into 4–8
   topic clusters. Name each cluster.
2. For each cluster, label the dominant search intent: informational,
   commercial, transactional or navigational.
3. Within each cluster, mark one primary "pillar" keyword and the rest as
   supporting long-tail terms.
4. Recommend one content format per cluster (guide, comparison, landing page,
   FAQ, tool) based on its intent.

Return this as a table: cluster | intent | pillar keyword | supporting terms |
recommended format. Then note which two clusters to prioritise and why.
